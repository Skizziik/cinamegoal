# Наше кино

Общий список фильмов для Максима и Алины: что хотим посмотреть, что уже посмотрели, оценки 1–10 и впечатления.

**Сайт:** https://skizziik.github.io/cinamegoal/

## Как это работает

- Статический сайт на GitHub Pages: без сборки, чистые ES-модули.
- Каждый фильм — issue в этом репозитории с меткой `cinemagoal`. Данные хранятся JSON-блоком в теле issue.
- Сайт опрашивает GitHub API каждые 10 секунд, так что изменения одного человека появляются у другого сами.
- Перед записью сайт перечитывает issue и меняет только нужные поля. Если два человека сохранили одновременно, клиент через пару секунд замечает потерянные правки и применяет их заново.
- Постеры и годы подтягиваются из Википедии.

## Доступ

Ключ доступа (fine-grained токен GitHub только с правом **Issues: read & write** на этот репозиторий) в коде **не хранится**.
Он приходит по ссылке-приглашению `https://skizziik.github.io/cinamegoal/#key=…` и сохраняется только в браузере.
Без ключа сайт открывается в режиме просмотра.

## Разработка

```bash
npm install
npx playwright install chromium webkit
npm run serve        # http://localhost:4173
npm test             # юнит-тесты (node:test)
npm run test:e2e     # e2e: iPhone (WebKit), Android (Pixel 7), десктоп
```
